The Johnson-Lindenstrauss Lemma: Why Random Projections Preserve Distance

March 30, 2026

Follow me on X and LinkedIn

Share:

You have $n$ points in $d$-dimensional space, where $d$ might be in the millions. The Johnson-Lindenstrauss lemma says you can project them down to roughly $O(\log n / \varepsilon^2)$ dimensions and preserve all pairwise distances within a factor of $(1 \pm \varepsilon)$. The target dimension does not depend on $d$ at all. This post explains why, from first principles.

1. Why care about random projections?

High-dimensional data is everywhere: word embeddings (300-1536 dimensions), genomics (20,000+ genes), image features (millions of pixels). Working in high dimensions is expensive. Distance computations scale as $O(d)$, nearest-neighbor search slows down, and storage costs grow linearly with $d$.

The standard response is dimensionality reduction. PCA finds the best low-rank approximation, but it needs to compute a covariance matrix ($O(nd^2)$ time) and is data-dependent. t-SNE and UMAP are great for visualization but don't preserve distances faithfully.

Random projections take a different approach: just multiply your data by a random matrix. No training, no eigendecomposition, no optimization. And the Johnson-Lindenstrauss (JL) lemma guarantees this works, with a target dimension that depends only on how many points you have and how much distortion you can tolerate.

2. The lemma, stated plainly

Johnson-Lindenstrauss Lemma (1984) $$ \text{For any } 0 < \varepsilon < 1 \text{ and any set } S \text{ of } n \text{ points in } \mathbb{R}^d, $$ $$ \text{there exists a map } f: \mathbb{R}^d \to \mathbb{R}^k \text{ with } k = O\!\left(\frac{\log n}{\varepsilon^2}\right) $$ $$ \text{such that for all } u, v \in S: $$ $$ (1-\varepsilon)\|u - v\|^2 \;\leq\; \|f(u) - f(v)\|^2 \;\leq\; (1+\varepsilon)\|u - v\|^2 $$

Every variable matters here:

  • $n$ is the number of points. The target dimension grows as $\log n$, so doubling your dataset adds roughly one extra dimension.
  • $d$ is the original dimension. It does not appear in the bound at all.
  • $\varepsilon$ controls distortion. Smaller $\varepsilon$ means more faithful distances but requires more dimensions ($k \propto 1/\varepsilon^2$).
  • $k$ is the target dimension. For $n = 1{,}000{,}000$ and $\varepsilon = 0.1$, you need roughly $k \approx 1400$ dimensions.
  • $f$ is a linear map: $f(x) = \frac{1}{\sqrt{k}} R x$ where $R$ is a $k \times d$ matrix with random entries.
Intuition: Imagine 1,000 cities on a map. You want to record all pairwise distances. Instead of storing full coordinates, you project them onto a few random directions and measure distances there. The JL lemma says roughly 70 random directions suffice to keep all 499,500 pairwise distances within 10% of the originals.

4. Why it works: concentration of measure

The proof rests on a single phenomenon: in high dimensions, random projections of a fixed vector concentrate tightly around the expected value. This is not obvious, and it is the reason the lemma feels almost too good to be true.

Start with one vector

Take a single unit vector $u \in \mathbb{R}^d$ and project it with a random matrix $R \in \mathbb{R}^{k \times d}$ whose entries are i.i.d. $\mathcal{N}(0, 1)$. The projected vector is $\frac{1}{\sqrt{k}} R u$.

The squared norm of the projection is:

Projected norm $$ \left\|\frac{1}{\sqrt{k}} R u\right\|^2 = \frac{1}{k} \sum_{i=1}^{k} (r_i \cdot u)^2 $$

Each $r_i \cdot u$ is a dot product of a random Gaussian vector with the fixed unit vector $u$. Since $u$ is unit length, $r_i \cdot u \sim \mathcal{N}(0, 1)$. So each $(r_i \cdot u)^2 \sim \chi^2(1)$, and the sum $\sum_{i=1}^k (r_i \cdot u)^2 \sim \chi^2(k)$.

What is $\chi^2$? The chi-squared distribution with $k$ degrees of freedom, written $\chi^2(k)$, is simply the distribution you get when you square $k$ independent standard normal random variables and add them up: $\chi^2(k) = Z_1^2 + Z_2^2 + \cdots + Z_k^2$ where each $Z_i \sim \mathcal{N}(0,1)$. So $\chi^2(1)$ is just a single squared Gaussian: it is always non-negative, skewed right, with mean 1 and variance 2. As $k$ grows, the sum concentrates: $\chi^2(k)$ has mean $k$ and variance $2k$, so the relative spread (standard deviation divided by mean) shrinks as $\sqrt{2/k}$.

A $\chi^2(k)$ random variable has mean $k$ and variance $2k$. Dividing by $k$, the projected squared norm has mean 1 and variance $2/k$. As $k$ grows, the variance shrinks and the projection concentrates around the true norm.

Intuition: Think of it as averaging $k$ independent, noisy measurements of the same quantity. Each measurement (one random direction) is unbiased but noisy. The average of $k$ measurements has $1/k$ the variance. More random directions means a more stable estimate of the true distance.

The diagram shows the distribution of the distance ratio $\|f(u)\|^2 / \|u\|^2$ for different target dimensions. With $k=2$, the distribution is wide and distances are unreliable. With $k=200$, nearly all the probability mass falls inside the $(1 \pm \varepsilon)$ band. The JL lemma quantifies exactly how much $k$ you need for a given $\varepsilon$ and $n$.

From one vector to all pairs

The concentration bound for a single vector says:

Single-pair failure probability $$ P\!\left[\left|\;\|f(u)\|^2 - \|u\|^2\;\right| > \varepsilon \|u\|^2\right] \;\leq\; 2\exp\!\left(-\frac{k\varepsilon^2}{4}\right) $$

This bound comes from a chi-squared tail inequality (a specific case of sub-exponential concentration; see Lemma 1 in Dasgupta and Gupta, 2003). Here is the reasoning in plain terms:

We showed that $\|f(u)\|^2 = \frac{1}{k}\sum_{i=1}^{k} X_i$ where each $X_i = (r_i \cdot u)^2 \sim \chi^2(1)$. The projected squared norm is the average of $k$ independent copies of the same random variable, and its expected value is $\|u\|^2$. The question is: how likely is this average to deviate from its expectation by more than a factor of $\varepsilon$?

The standard tool is a moment generating function (MGF) bound, which works like this:

  1. For any $t > 0$, the event $\{Y > a\}$ is equivalent to $\{e^{tY} > e^{ta}\}$. By Markov's inequality, $P[Y > a] \leq \mathbb{E}[e^{tY}] / e^{ta}$. This is the Chernoff bound technique: convert a probability question into a bound on the MGF.
  2. For a $\chi^2(1)$ random variable $X$, the MGF is $\mathbb{E}[e^{tX}] = (1 - 2t)^{-1/2}$ for $t < 1/2$. Since the $X_i$ are independent, the MGF of the sum $\sum X_i$ is the product of individual MGFs: $(1 - 2t)^{-k/2}$.
  3. Optimize over $t$ to get the tightest bound. After algebraic simplification (using $\ln(1-x) \leq -x - x^2/2$ for the upper tail, and the analogous bound for the lower tail), both tails contribute at most $\exp(-k\varepsilon^2/4)$ each.
  4. A union bound over both tails (the projected norm could be too large or too small) gives the factor of 2.
Intuition: The Chernoff bound says that the probability of an average deviating from its mean decays exponentially in the number of samples $k$. With $k$ random directions, the chance of a bad projection drops as $e^{-ck\varepsilon^2}$. This is much stronger than what Chebyshev's inequality ($1/k\varepsilon^2$) gives, and it is what makes JL practical: you need $k$ proportional to $\log n$, not $n$.

For the lemma, we need this to hold for all $\binom{n}{2}$ pairs simultaneously. Apply a union bound: the probability that any pair fails is at most $\binom{n}{2} \cdot 2\exp(-k\varepsilon^2/4) < n^2 \exp(-k\varepsilon^2/4)$.

Set this less than some small $\delta$ and solve for $k$:

Required target dimension $$ k \;\geq\; \frac{4}{\varepsilon^2}\left(2\ln n + \ln\frac{1}{\delta}\right) \;=\; O\!\left(\frac{\log n}{\varepsilon^2}\right) $$

The $\log n$ comes from the union bound over $n^2$ pairs. The $1/\varepsilon^2$ comes from the Gaussian tail. Neither term involves $d$.

Intuition: Each pair needs the same fixed $k$ for concentration. The only reason $k$ grows with $n$ is that you have more pairs that could fail. But the number of pairs grows as $n^2$, and $\log(n^2) = 2\log n$, so the growth is gentle. Going from 1,000 to 1,000,000 points only doubles $k$.

5. The projection matrix

The map $f(x) = \frac{1}{\sqrt{k}} R x$ uses a $k \times d$ random matrix $R$. Several distributions for the entries of $R$ work:

DistributionEntry $R_{ij}$Notes
Gaussian$\mathcal{N}(0,1)$Cleanest theory, dense matrix
Rademacher$\pm 1$ with equal probEqually good, faster to generate
Sparse (Achlioptas)$\{-1, 0, +1\}$ with prob $\{1/6, 2/3, 1/6\}$2/3 of entries are zero, ~3x faster matrix multiply

All three satisfy the JL guarantee. The key requirement is that each entry has mean 0, variance 1, and is independent. The Gaussian version is cleanest for proofs; the sparse version is most practical.

The $\frac{1}{\sqrt{k}}$ scaling factor is important. Without it, the projected norms would grow with $k$. Dividing by $\sqrt{k}$ ensures the expected squared norm is preserved: $\mathbb{E}[\|f(x)\|^2] = \|x\|^2$.

6. Where $O(\log n / \varepsilon^2)$ comes from

The two factors in $k = O(\log n / \varepsilon^2)$ come from different parts of the argument:

The $1/\varepsilon^2$ factor: tail width

The projected squared norm is an average of $k$ chi-squared random variables. By the central limit theorem (or more precisely, sub-exponential concentration), the probability of deviating by more than $\varepsilon$ from the mean decays as $\exp(-c k \varepsilon^2)$ for some constant $c$. To make this probability small, you need $k \geq C/\varepsilon^2$. Halving $\varepsilon$ quadruples the required $k$.

The $\log n$ factor: union bound tax

You have $\binom{n}{2} < n^2$ pairs of points. Each pair independently has a small failure probability $\delta_{\text{pair}} \leq 2\exp(-ck\varepsilon^2)$. To ensure all pairs succeed simultaneously, you need:

$$ n^2 \cdot 2\exp(-ck\varepsilon^2) < 1 \quad \Rightarrow \quad k > \frac{2\ln n + \ln 2}{c\varepsilon^2} $$

The $\ln n$ comes from needing to "pay" for $n^2$ chances of failure. But since it is logarithmic, the cost is remarkably low:

Going from 100 points to a billion only increases $k$ by about 4x. This is the remarkable part of JL: the target dimension grows so slowly with $n$ that it is practical for almost any dataset size.

7. Practical notes

When to use random projections

  • Approximate nearest neighbors. Project high-dimensional vectors to $O(\log n / \varepsilon^2)$ dimensions, then run exact nearest-neighbor search in the lower-dimensional space. The $\varepsilon$-distortion translates directly to retrieval quality.
  • Preprocessing for clustering. K-means and DBSCAN are expensive in high dimensions. Project first, then cluster. Distance-based clustering algorithms are preserved by JL.
  • Sketching and streaming. Random projections can be applied row-by-row as data arrives. No need to see the full dataset first (unlike PCA).
  • Privacy. The random projection matrix can serve as a one-way transformation: you cannot recover the original data from the projection, but distances are preserved for downstream tasks.

When NOT to use random projections

  • When $d$ is already small. If your data is 50-dimensional, projecting to 40 dimensions saves almost nothing and adds noise.
  • When you need exact distances. JL gives $(1 \pm \varepsilon)$ approximation, not exact preservation. For applications that need precise distances, this is not enough.
  • When structure matters more than distance. PCA captures the directions of maximum variance. Random projections do not. If your data lies near a low-dimensional subspace and you want to find that subspace, use PCA.

Implementation in Python

A minimal implementation is five lines: 

import numpy as np

def jl_project(X, k):
    """Project n x d matrix X to n x k using Gaussian random projection."""
    d = X.shape[1]
    R = np.random.randn(k, d) / np.sqrt(k)
    return X @ R.T

scikit-learn provides sklearn.random_projection.GaussianRandomProjection and SparseRandomProjection with automatic $k$ selection via the JL bound. For large-scale use, the sparse variant is significantly faster.
